# NetFree Widget - ווידג'ט מעקב גלישה לנטפרי

ווידג'ט ללוח הווידג'טים של Windows 11 למעקב אחר נפח הגלישה בנטפרי.

## תכונות

- 📊 נפח שנוצל מול גודל החבילה
- 📈 חישוב חריגה יומית חכם (כולל מצב סופ"ש של יום אחד או שניים)
- 🔮 תחזית סיום חבילה
- 📏 3 גדלים: Small, Medium, Large
- 🔄 כפתור רענן
- ⚙️ טופס הגדרות בתוך הווידג'ט
- 🧭 זיהוי אוטומטי של יום האיפוס, כשהוא לא ידוע
- 🪶 צריכת משאבים נמוכה: אין עבודה ברקע, בקשת רשת אחת משותפת עם מטמון, והתהליך נסגר כשאין ווידג'טים

## מבנה הפרויקט

```
NetFreeWidget/
├── NetFreeWidget.Core/               # לוגיקה (API, חישובים, מודלים)
├── NetFreeBoardWidgetProvider/       # COM server ו-IWidgetProvider
├── NetFreeBoardWidgetPackage/        # אריזת MSIX ונכסים
└── Installer/                        # מתקין לפעם הראשונה (תעודה + התקנה עם עדכונים)
```

## דרישות מערכת

- Windows 11
- Visual Studio 2022 עם רכיב Windows App SDK / MSIX Packaging (לפיתוח)
- Developer Mode (לבדיקות מקומיות)

## התקנה למשתמשים

להוריד ולהריץ את [NetFreeWidget-Setup.exe](https://github.com/Y-PLONI/NetFreeWidget/releases/latest/download/NetFreeWidget-Setup.exe).

- המתקין מבקש אישור מנהל פעם אחת, כדי לסמוך על תעודת החתימה (`CN=Y-PLONI`), ואז מתקין את הווידג'ט למשתמש המחובר.
- ההתקנה נעשית דרך קובץ `.appinstaller`, ולכן Windows בודק עדכונים בעצמו (בערך כל 8 שעות) ומתקין כל Release חדש בלי שום פעולה מצד המשתמש.
- ברשתות שבהן Windows לא מצליח להוריד את החבילה בעצמו (למשל בנטפרי, שגיאה `0x80D05011`), המתקין מוריד את הקבצים בעצמו ומתקין אותם מקומית, ורק את התלויות שחסרות. במקרה כזה העדכונים האוטומטיים לא נרשמים, ולעדכון מריצים שוב את המתקין.
- בלי חיבור לכתובות של GitHub אפשר להתקין ידנית עם `install.ps1` מה-Release (בלי עדכונים אוטומטיים).

### חתימה

כל ה-Releases נחתמים באותה תעודה חתומה-עצמית, שנשמרת בסודות של המאגר: `SIGNING_PFX_BASE64` (קובץ ה-pfx ב-Base64) ו-`SIGNING_PFX_PASSWORD`. ה-Publisher במניפסט חייב להיות זהה לנושא התעודה. אם מחליפים תעודה, משתמשים קיימים יצטרכו להריץ את המתקין שוב.

## בנייה והתקנה (פיתוח)

ראה [QUICK_START.md](QUICK_START.md) להתחלה מהירה, או [WIDGET_SETUP_GUIDE.md](WIDGET_SETUP_GUIDE.md) למדריך מלא.

```powershell
# בנייה (Release כברירת מחדל) והתקנה
.\build-and-deploy.ps1 -Platform x64

# או ב-Visual Studio:
# 1. פתח NetFreeWidget.sln
# 2. Set Startup Project: NetFreeBoardWidgetPackage
# 3. Build + Deploy
```

> שים לב: `dotnet build` לא מספיק. יש לבנות עם MSBuild של Visual Studio (הסקריפט עושה זאת).

## הגדרות

לוחצים על **"הגדרות"** בכרטיס, או בוחרים "התאמה אישית" בתפריט של הווידג'ט. בטופס שנפתח ממלאים:

- **נפח החבילה (GB)**
- **יום האיפוס בחודש**: אפשר לבחור "לא ידוע - זיהוי אוטומטי" (ראו בהמשך).
- **חישוב סוף השבוע**: שישי ושבת כשני ימים, או כיום אחד.

ההגדרות נשמרות בקובץ `%APPDATA%\NetFreeWidget\settings.json`.

## זיהוי אוטומטי של יום האיפוס

אם יום האיפוס לא ידוע, הווידג'ט לומד אותו לבד: בכל קריאה הוא שומר את הצריכה, וכשהיא יורדת פתאום הוא מסיק שהחבילה התאפסה בין שתי הקריאות האחרונות. המעקב נשמר בנפרד לכל חשבון נטפרי (`tracking-<userId>.json` באותה תיקייה), כך שמעבר בין רשתות של חשבונות שונים לא נראה כמו איפוס.

- **המחשב דלק ביום האיפוס:** הטווח מצטמצם ליום או יומיים.
- **המחשב כבה סביב האיפוס:** מתקבל טווח רחב יותר (למשל 11–18 לחודש). כל איפוס נוסף בחודש הבא מצמצם אותו, כי ימים שלא התאימו לאחד האיפוסים נפסלים.
- **ימים שנצפו במלואם בלי איפוס** נפסלים כבר לפני האיפוס הראשון.

### איך מוצג מצב לא ודאי

- **אחוז הצריכה** ("נוצל 45%") מדויק תמיד, כי הוא לא תלוי במועד האיפוס.
- **החלק שעבר מהחודש** והצריכה התקינה להיום מוצגים כטווח, למשל "עבר 43–50% מהחודש" ו"תקין להיום: 43.33–50.00 GB".
- **המסקנה** ("תקין" או "חריגה") מוצגת רק אם היא נכונה לכל יום איפוס אפשרי, והמספר שמוצג הוא המינימום המובטח ("נותרו לפחות 25.7 GB"). אם התשובה תלויה ביום המדויק, יוצג "גבולי: תלוי במועד האיפוס המדויק".
- **לפני שיש מספיק מידע** (יותר מ-10 ימים אפשריים) מוצג רק אחוז הצריכה, עם ההודעה "לומד את מועד האיפוס...".

## עדכון נתונים

- הנתונים מתעדכנים בכל פתיחה של לוח הווידג'טים, ונשמרים במטמון ל-10 דקות.
- כפתור "רענן" עוקף את המטמון (עם מרווח מינימלי של 10 שניות).
- כשאין חיבור, הניסיונות מתרווחים בהדרגה (30 שניות עד 15 דקות).
