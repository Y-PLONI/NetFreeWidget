NetFree Widget — icon pack
==========================

NetFreeWidget.svg / .png / .ico
    App icon with a light rounded-square backing.

NetFreeWidget-transparent.svg / .png / .ico
    The same mark without the backing. Transparent RGBA PNG and ICO.

PNG/
    Raster exports from 16 through 512 px. Main PNG files are 1024 x 1024.
    The 16–32 px versions omit small dial ticks for better readability.

The meter is decorative; its pictured level does not represent live usage.
No fonts, linked images, external assets or scripts are required by the SVGs.
No project files have been modified.
